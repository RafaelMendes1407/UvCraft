# UvCraft 0.1.0

First public desktop release for Linux and Windows (x86-64).

## Highlights

- 3D and UV viewports for seam cutting, unfolding, island editing, grouping, stacking, packing, and distortion analysis.
- Local Blender add-on bridge: send selected meshes to UvCraft and receive UV coordinates and seams without changing 3D topology.
- In-app Blender add-on installer and a complete [user guide](https://github.com/RafaelMendes1407/UvCraft/blob/main/docs/user-guide.md).

## Downloads

- **Linux:** `UvCraft-v0.1.0-linux-x86_64.tar.gz`. Extract it and run `./uvcraft-app`. To install a per-user desktop launcher, run `sh packaging/linux/install.sh ./uvcraft-app` inside the extracted folder.
- **Windows:** `UvCraft-v0.1.0-windows-x86_64.zip`. Extract it and run `uvcraft-app.exe`.

Both archives include the Blender add-on source under `blender-addon/uvcraft_blender`. The desktop app can also install the add-on through **File → Install Blender add-on…**.

The Blender bridge transfers UVs and seams manually. Group metadata and stack relations stay in UvCraft's `.uvcraft.json` sidecar when saving a mesh from the desktop app.

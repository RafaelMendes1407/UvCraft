# UvCraft 0.1.1

Security release for Linux and Windows (x86-64). It hardens how UvCraft reads files and listens for connections that may come from untrusted sources. Projects, scripts and the Blender add-on from 0.1.0 keep working, with the one exception listed under **Behavior changes**.

## Security fixes

- **glTF loading:** a file whose JSON root is not an object now returns an error instead of crashing. Fuzzing found this one.
- **External glTF buffers** are only read from regular files inside the asset's own folder. Absolute paths, URI schemes, `..` segments, symlinks that lead outside the folder and device files such as `/dev/zero` are rejected. Before this, a crafted `.gltf` could hang the loader or copy an unrelated file into a later `.glb` export.
- **`uvcraft serve`** now refuses non-loopback addresses, like the Blender bridge already did. Each JSON-RPC request line is capped at 64 MiB.
- **Preferences** are written through an exclusive temporary file readable only by you, and never through a symbolic link.

## New

- **Clear saved data:** the new button in **Preferences** deletes the preferences file, which holds selection sets, layout presets and recently used mesh and texture paths. `uvcraft-app --clear-preferences` does the same from a terminal.

## Behavior changes

- A `.gltf` that references buffers outside its own folder (for example `../buffers/mesh.bin`) no longer opens. Move the `.bin` next to the `.gltf`, or convert the asset to `.glb`.
- `uvcraft serve --bind` only accepts loopback addresses such as `127.0.0.1` or `[::1]`.

## For contributors

- New security audit (`./scripts/security-audit.sh`) and CI workflow: dependency advisories, license and source policy, strict formatting and Clippy, the `unsafe_code = "forbid"` policy, an unsafe inventory, secret scanning, CycloneDX SBOMs and fuzzing of OBJ, glTF/GLB, FBX and command scripts. See [docs/SECURITY_AUDIT.md](https://github.com/RafaelMendes1407/UvCraft/blob/main/docs/SECURITY_AUDIT.md) and [SECURITY.md](https://github.com/RafaelMendes1407/UvCraft/blob/main/SECURITY.md).
- Release actions are pinned to commit SHAs, and Dependabot tracks Cargo and Actions updates.

## Downloads

- **Linux:** `UvCraft-v0.1.1-linux-x86_64.tar.gz`. Extract it and run `./uvcraft-app`. To install a per-user desktop launcher, run `sh packaging/linux/install.sh ./uvcraft-app` inside the extracted folder.
- **Windows:** `UvCraft-v0.1.1-windows-x86_64.zip`. Extract it and run `uvcraft-app.exe`.

Both archives include the Blender add-on source under `blender-addon/uvcraft_blender`.
